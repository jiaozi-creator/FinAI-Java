📌 第一步：安装必需软件
═══════════════════════════════════════════════════════

1. Java 17+
   下载: https://adoptium.net/
   选择: Temurin 17 (LTS) - Windows x64
   安装后验证: 打开cmd，输入 java -version

2. Maven 3.6+
   方法1 (推荐): choco install maven
   方法2: https://maven.apache.org/download.cgi
   验证: mvn -version

3. Node.js 18+
   下载: https://nodejs.org/
   选择: LTS版本
   验证: node --version

📌 第二步：配置项目
═══════════════════════════════════════════════════════

1. 打开项目文件夹 FinAI-Java

2. 复制 .env.example 为 .env
   (右键复制，重命名为 .env)

3. 用记事本打开 .env，填入你的API密钥：
   
   LLM_PROVIDER=claude
   ANTHROPIC_API_KEY=你的Claude密钥
   
   或者使用OpenAI:
   LLM_PROVIDER=openai
   OPENAI_API_KEY=你的OpenAI密钥

📌 第三步：启动项目
═══════════════════════════════════════════════════════

方式1 (推荐) - 双击运行:
   找到 run_all.bat 文件
   双击运行
   等待自动启动

方式2 - 命令行运行:
   1. 按 Win+R，输入 cmd
   2. cd 到项目目录
   3. 运行: run_all.bat

📌 第四步：访问应用
═══════════════════════════════════════════════════════

浏览器打开:
   前端界面: http://localhost:5173
   API文档:  http://localhost:8080/swagger-ui.html

📌 常见问题
═══════════════════════════════════════════════════════

Q: 提示"Java版本过低"？
A: 确保安装了JDK 17或更高版本

Q: 提示"端口被占用"？
A: 关闭占用8080或5173端口的程序
   或在cmd中运行:
   netstat -ano | findstr :8080
   taskkill /PID 进程号 /F

Q: Maven构建失败？
A: 检查网络连接，Maven需要下载依赖包

Q: 前端页面打不开？
A: 等待30秒，后端需要启动时间

📌 停止服务
═══════════════════════════════════════════════════════

直接关闭两个命令窗口:
   - FinAI-Backend
   - FinAI-Frontend

或在窗口中按 Ctrl+C

# FinAI 金融投研智能体项目计划书

竞赛：北京市大学生金融人工智能竞赛  
主题：金融投研智能体构建  
选题：2. 上市公司财务报告分析；4. 自动化估值建模  
文档版本：2026-09-27  
提交说明：组委会要求初赛计划书为 PDF。本文是仓库内的源稿，导出 PDF 后上传竞赛平台。队员、学校、指导老师待报名表确认后填入，不在本文编造。

## 1. 要解决的问题

投研里最容易失真的一步，是把年报里的数字交给大模型“看懂并算完”。模型会改口径、补缺失值、把假设写成事实。评审同时要求结果可核验、过程可追溯、运行可复现。

本作品把数字和表述拆开：

- 数字只由程序从文本层财报中抽取，并用 BigDecimal 计算。缺列保持空，不补零，不编造。
- 大模型只在计算完成后写表述。它只能读取已经算好的工具结果。表述里出现工具结果对不上的数字时，该段退回程序文本。

当前主路径仍是固定流水线，不是由模型决定先调哪个工具。这一点在第 3 节写明，不把流水线叫成自主规划。

## 2. 目标与边界

### 2.1 本期目标

给定一份文本层可复制的年度、半年度或季度报告（PDF 或 txt），系统完成：

1. 抽取合并口径优先的主表科目，保留页码、单位、原文片段。
2. 计算同比和主要财务比率。单份报告不计算环比。
3. 做资产负债表勾稽。
4. 用三条规则识别非经常性损益差额、利润与现金流背离、会计政策或估计变更。
5. 在经营现金流和历史增速齐备时，做五年 FCFF 折现，输出区间、假设表和敏感性矩阵。
6. 输出结构化报告，并区分事实、推论、观点。
7. 记录文件 SHA-256、工具入参与输出、模型名、温度、提示词与技能版本，以及本次调用是否离开本机。

### 2.2 明确不做

以下方向不在本期计划内。接口若仍存在，只返回「未计算」，不输出数字：

- 选题 1 公告字段、选题 3 产业链、选题 5 研报纠错、选题 6 买方备忘录、选题 7 报告质量评估。
- 扫描件和 OCR。文本层抽不到就留空。
- 相对估值、市盈率、市净率、EV/EBITDA。没有市价和可比公司底稿。
- 分产品、分渠道收入。主表字段字典里没有这些行，不从正文猜测。
- 行业排名、时间序列预测。
- 把 WACC、永续增长率写成公司事实。当前折现率 9%、永续增长 2% 是模型假设。无风险利率、Beta、股权风险溢价没有入库来源，不写成已计算的 WACC。

## 3. 方案

```
上传财报
  -> 记录文件哈希，按页抽出文本层
  -> 按表头记住当前是合并表、母公司表、摘要还是附注
  -> 字段字典匹配科目，同一字段只留优先级最高的一行
  -> 同比、比率、勾稽
  -> 三条异常规则
  -> 简化 DCF 与敏感性
  -> 技能约束下的表述（只能读工具结果）
  -> 结构化报告 + 审计日志
```

计算模块在 `backend/src/main/java/com/finai/analysis`。模型调用在这条链的最后一步，不参与抽取和公式。任务顺序由 `TaskExecutionWorker` 写死。`SkillNarrator` 在叙述时调用 `statement.metrics`、`statement.evidence`、`articulation.check`、`anomaly.rules`、`valuation.dcf`。`/api/mcp/tools` 提供同一批结果的只读查询，不负责决定步骤。

| 模块 | 代码 | 职责 |
| --- | --- | --- |
| 任务编排 | `TaskExecutionWorker` | 按固定顺序执行，写入任务状态和工具审计 |
| 字段字典 | `config/field_dict.yaml` | 科目 id、名称、行首别名。不含口径优先级 |
| 抽取 | `StatementExtractor` | PDFBox 文本层或 txt；按表头区分合并、母公司、摘要、附注 |
| 证据 | `EvidenceStore` | 每个科目的页码、单位、原文 |
| 计算 | `MetricCalculator` | 同比、毛利率、净利率、ROE、ROA、流动比率、现金流覆盖 |
| 规则 | `config/rules.yaml`、`AnomalyRuleEngine` | 三条已实现规则及阈值 |
| 估值 | `ValuationEngine` | 五年 FCFF、情景、敏感性；缺输入则不给区间 |
| 技能与提示词 | `skills/financial-statement-analysis.md`、`prompts/report-narrative.md` | 运行时加载 |
| 表述 | `SkillNarrator` | 模型只能调用已算好的工具 |
| 审计 | `audit_log` | 文件访问、工具、模型请求全文 |
| 界面 | `frontend`（React） | 建任务、看指标、看来源、看报告 |

抽取时，同一科目可能在摘要、合并主表、母公司主表、收购附注里各出现一次。程序先按表头给行打口径，再按「合并主表 > 主要会计数据 > 未识别正文 > 母公司主表 > 附注」保留一行。带「归属于」或「扣除非经常」的原文再优先于短科目名「净利润」。科目和金额被拆到相邻行时，向后最多看两行。扣非若行首对不上字典，只接受同一行里同时出现的本期和上期。

模型默认通义千问 `qwen-plus`，经阿里云 DashScope 兼容接口调用，温度 0.0。未配置 `ALIYUN_API_KEY` 时使用本地 mock，不发外网请求，报告标明「未调用」。

## 4. 财务口径

事实只来自抽到的列示数。

- 同比 = (本期 − 上期) / |上期|。上期来自同一行的对比列。上期缺失或为 0 时不计算。
- 毛利率 = (营业收入 − 营业成本) / 营业收入。净利率 = 归母净利润 / 营业收入。分子分母单位不一致则不计算。
- ROE = 归母净利润 / 期末归母权益。分母不是期初期末平均权益。
- ROA = 归母净利润 / 期末总资产。
- 资产负债率 = 负债合计 / 资产总计。流动比率 = 流动资产合计 / 流动负债合计。
- 勾稽检查资产与负债加权益。少数股东权益抽到且单位一致时计入权益。相对差额在 1% 以内视为通过。
- 非经常性损益规则比较的是主表归母净利润与扣非净利润的差额占归母净利润的比例，阈值 0.20，达到 0.50 记为高。这个差额不是附注合计数。
- 利润与现金流背离：归母净利润为正，且出现符号背离、经营现金流覆盖低于 0.50，或利润同比上升同时经营现金流同比下降。
- FCFF 在资本开支抽到且单位一致时取经营现金流减资本开支。缺资本开支时，假设表写明暂用经营现金流代替。预测期 5 年，增速用收入同比并限制在 ±30%。股权价值 = 企业价值 − (短期借款 + 长期借款 − 货币资金)。三项不齐则不桥接，区间使用企业价值。
- 低高区间为增速 ±2 个百分点。敏感性为 WACC 7%–11%、永续增长 0%–4%。
- 相对估值不计算。

推论是规则命中和折现结果。观点是模型表述和投资含义，报告写明不构成投资建议。

页面上，资产负债表科目、自由现金流、每股收益的同比列目前固定为空，即使上期已经抽到。这是展示问题，不是抽取失败。

## 5. 数据与复现

运行数据放在本机：

- 上传文件在 `backend/data/uploads`（从 `backend` 目录启动时）。
- 任务、证据、审计存在 H2 文件库 `backend/data/finai.mv.db`。同一时间只能有一个后端进程打开该文件。
- 人造短文本：`backend/src/main/resources/samples/demo-statement.txt`。`test-data/maotai_2023_annual_report.txt` 是摘录，内部勾稽不成立，不能当金标准。
- 已核对的文本层年报：`test-data/filings/603313_2025_annual.pdf`（梦百合 2025 年年度报告更正后）。文件 SHA-256 为 `dec798723b1b312107ec8bc817a1a0c274175d7de4c545906c83116c1625c5fc`。

封闭性：财报原件不出域。配了密钥时，离开本机的是技能、提示词和已经算好的工具结果。审计字段 `leavesMachine` 记录这一点。

复现一次任务需要：同一份文件、同一套 `config/`、同一模型名和温度、审计日志中的完整提示词。模型输出本身受服务端影响。指标、规则和估值不依赖模型，无密钥时可以复现。旧任务存在库里的结果不会随代码更新，演示抽取修复后的结果需要重新上传并新建任务。

### 7.1 决赛前的代码工作

1. 规划记录。用户问题先落成步骤（取数、指标、勾稽、风险、估值、备忘录）。分析类型为仅估值时不跑风险工具。每步记下工具名、输入、输出和耗时，任务页放在指标上面。数字仍只来自现有计算模块。
2. 已有字段能算、但还没算的比率：毛利率、净利率、ROE 相对上期的变化；速动比率；有息负债率（短借 + 长借）/ 总资产；应收账款和存货同比。缺列留空。不算 ROIC、现金转换周期和收入拆分。
3. 任务页同比列与抽取结果一致。已有上期的资产负债科目不要显示成未提取。自由现金流的证据指向经营现金流和资本开支，不单指向资本开支。
4. 梦百合手填金标准，以及字段命中率。审计报告中的保留意见只有在正文原句抽到时才作为风险信号，不预写结论。

### 7.2 视频

只演示：上传文本层 PDF、指标与来源页码、三条规则、DCF 假设表（明确 9% 和 2% 是假设）、审计里的文件哈希和工具记录。不演示行业排名、预测、扫描件。

## 8. 第三方

模型权重和商业软件源码不提交。使用范围以 `docs/runbook.md` 的第三方表为准。Spring Boot、LangChain4j、PDFBox、H2、React、Ant Design 均为开源依赖。通义千问仅在配置密钥后用于表述。不得把这些依赖写成自主模型或自主 PDF 引擎。

## 9. 风险

- 表头不在行首、列顺序不是本期然后上期、科目被拆成很短的碎片时，仍会抽错或漏抽。抽不到保持空。
- 扣非「同一行两个金额」是针对主要会计数据折行的规则，不是通用表格解析。
- 简化 FCFF 不含营运资本变动、税率、少数股东和非核心资产。适用边界写在假设表中。
- H2 文件锁会导致第二个后端启动失败。演示前只留一个进程。
- 若现场网络不能访问阿里云，系统退回程序表述，数字结果仍然可展示。
